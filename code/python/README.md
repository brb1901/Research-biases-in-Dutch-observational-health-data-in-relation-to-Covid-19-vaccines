Python scripts used in the project. Most were used within the CBS Microdata environment, based on individual-level pseudonymized data. They cannot be run directly without having access to CBS Microdata.
There are preprocessing scripts and analysis scripts (even though the distinction is not 100% clear-cut). 

There is no extensive documentation and most of the code cannot be run out of the box; the code is mostly provided for completeness, information and checking purposes. Contact the maintainer of this repository, who is also the first author of the paper that this repository belongs to, for detailed explanation.
